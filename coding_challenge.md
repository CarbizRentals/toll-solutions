# Coding challenge — sort a list

Sort a list of numbers. Use any programming language, or pseudocode if you prefer not to write runnable code.

## The change

You are given a list of numbers. Return a new list with the same numbers in ascending order. Leave the original list unchanged.

```text
sort_list([4, 1, 3])  →  [1, 3, 4]
```

## Cases

| Input | Expected result |
|---|---|
| `[4, 1, 3]` | `[1, 3, 4]` |
| `[]` | `[]` |
| `[7]` | `[7]` |
| `[2, 2, 1]` | `[1, 2, 2]` |
| `[1, 2, 3]` | `[1, 2, 3]` |
| `[3, -1, 0]` | `[-1, 0, 3]` |

## What to hand back

1. The code or pseudocode that performs the sort.
2. Two or three sentences on why you chose that approach.
3. The result of each case above.

A language's built-in sort is acceptable. If you use one, say what it guarantees about equal values and about the original list.
